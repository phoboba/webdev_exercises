# Phoebe's Web Development Exercises
This project is a refresher on how web development works (HTML/CSS/JS) for myself using the University of Kent's COMP5011 Fundamentals of Web Development 2025-26 Class Exercises.\
It is also a way for me to learn how to initialise a repository and learn how to do version control, involving the following:
- Complete the tasks for each week at a good pace, updating when significant changes have been made.
- Learn the difference between committing and pushing changes.
- Learn what pulling requests are, when to use them and why they are important.
- Create meaningful messages when pushing changes, summarising what has been done and where.

## End-Goal for this Project
I'm hoping to show off some development in my knowledge when it comes to web development, and hopefully move on to working with databases and web development.\
What needs to be done:
- [ ] Understand Basic HTML using the tasks from Week 1.
- [ ] Understand how styling with CSS works using the tasks from Week 2.
- [ ] Understand how to use flex boxes in CSS to personalise layout using tasks from Week 3.
- [ ] Use animations and create shapes in CSS using tasks from Week 4.
- [ ] Begin JavaScript practice using tasks from Week 5.
- [ ] Learn more JavaScript using tasks from Week 6.
- [ ] Build a webpage with hyperlinks to each week to showcase each task from a main (index) page.
